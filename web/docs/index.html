RunLater

Local prototype guide

No public API is deployed. The planned API host is api.runlater.io. All commands below target a developer's local emulator.

Try a task

Follow the repository's local setup guide. Fixture tokens are public test data and must never be used for production.

curl http://127.0.0.1:8787/v1/tasks \
  -H 'Authorization: Bearer local-alpha' \
  -H 'Idempotency-Key: hello' \
  -H 'Content-Type: application/json' \
  -d '{"operation_key":"hello_1","destination":"fixture://success","body":"hello","run_at_ms":0}'

Delivery guarantees

At least once is the design target. Delivery can be duplicated after an uncertain result. No ordering or exact-time guarantee. Cancellation cannot undo an in-flight side effect. Redrive creates a new linked execution.

Safety boundary

Only three in-process fixture destinations are accepted: success, retry, and fail. All real URLs are rejected. No customer credentials or payloads are logged. The API contract and unresolved launch gates live in the repository.
