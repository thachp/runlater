Less waiting around

A small API.
A durable memory.

Give long-running agents a way to come back to a task, without keeping the original process awake.

01 / SCHEDULE

Leave a task for later.

Submit a one-time task with a stable idempotency key. The durable ledger keeps accepted work through restarts.

02 / DELIVER

Make room for retries.

Failures have finite attempt and age budgets. Signed callbacks carry a stable operation key for receiver deduplication.

03 / INSPECT

See what actually happened.

Read task state and attempt outcomes. Cancel work that hasn’t been claimed; an in-flight effect may still happen.

Where we are today

Small on purpose.
Honest about the edges.

We’ve verified signed HTTPS delivery, retries across key rotation, redirect rejection and timeout handling in a controlled cloud test. The retained alpha keeps that same narrow boundary.

Delivery is at least once. Duplicates are possible. No exact-time, ordering or exactly-once promise.
